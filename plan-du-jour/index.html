Recrée Embage seul, en 5 jours

Embage permet de créer un agent IA (chat et voix) sur ton site web, sans coder : il répond à tes clients, collecte leurs infos et orchestre des workflows. Voici le plan pour construire ta version française, avec Claude Code.

Pourquoi c'est un bon pari

  • Un besoin universel. Un visiteur arrive, pose une question, personne ne répond — il part. 78 % des consommateurs français attendent une réponse en moins de 5 minutes.
  • Une demande prouvée. 135 upvotes et #4 sur Product Hunt le jour du lancement. La veille, Knocket (live chat sans IA) prenait la #2 : la progression naturelle, c'est l'IA qui répond à ta place.
  • Aucun équivalent français abordable. Crisp facture l'IA à 95 €/mois. Brevo demande 800 €/mois. Personne ne propose un agent IA vocal no-code à moins de 20 €/mois en France.
  • Techniquement faisable. API Claude en streaming + Web Speech API (gratuit, natif navigateur) + ElevenLabs pour la voix. Pas de modèle à entraîner.
Ton angle de différenciation

La version française, RGPD-native, à 19 €/mois : interface en français, données hébergées en UE (Supabase Francfort), voix française naturelle, et Mistral en option pour la souveraineté. Cible : indépendants, artisans, professions libérales qui n'ont pas de secrétaire.

Le MVP

Cinq fonctionnalités, pas une de plus pour la première version.

MVP

Widget chat IA

Un script JS à coller. L'agent répond automatiquement via Claude, en streaming, sur n'importe quel site.

MVP

Agent voix

Le visiteur clique sur un micro, parle dans le navigateur, l'IA répond oralement. Conversation vocale sans téléphone.

MVP

Base de connaissances

Upload tes PDF, Word, CSV. L'agent y puise ses réponses grâce à une recherche sémantique.

MVP

Collecte de données

Chaque conversation génère une fiche structurée : nom, email, besoin, score de qualité. Export CSV.

MVP

Dashboard

Liste des conversations, fiches contact, personnalisation de l'agent (prompt, couleurs, avatar), analytics.

  • Hors V1 : intégration Telegram/WhatsApp, multi-utilisateurs, API publique, workflows avancés.

Le plan jour par jour

Chaque jour a son prompt prêt à coller dans Claude Code. Lance-le dans un dossier vide, puis relis et teste avant de passer au suivant.

J1

Widget chat IA + backend

  • Créer le projet Next.js + Supabase (région EU).
  • Tables agents, conversations, messages avec Row Level Security.
  • Route /api/chat : appelle Claude en streaming.
  • Widget JS (~8 ko) : bulle de chat en bas à droite.
Fin de journéeUn widget s'affiche sur une page test et l'IA répond en temps réel.
Prompt Claude Code · J1
Crée une application Next.js (App Router, TypeScript, Tailwind), interface en français.
Intègre Supabase (région eu-central-1) avec les tables :
- agents (id, user_id, name, system_prompt, avatar_url, colors JSON, created_at)
- conversations (id, agent_id, visitor_id, status, metadata JSON, created_at)
- messages (id, conversation_id, role, content, created_at)
Active Row Level Security sur chaque table.
Crée une route /api/chat qui reçoit {agent_id, conversation_id, message}, charge le system_prompt de l'agent, appelle Claude Sonnet en streaming via le SDK Anthropic, et renvoie la réponse en streaming (ReadableStream).
Crée un composant Widget (iframe-ready) : bulle en bas à droite, champ de saisie, messages en temps réel avec streaming. Le widget est exportable via un script JS autonome qui s'injecte sur n'importe quel site.
Gère les erreurs : si Claude échoue, affiche un message d'excuse et propose un email de contact.
Ajoute un fichier .env.example et un README.
J2

Voix + base de connaissances

  • Web Speech API pour la transcription vocale.
  • ElevenLabs Turbo pour la synthèse française.
  • Upload de documents + découpage en chunks.
  • Recherche sémantique (pgvector) avant chaque réponse.
Fin de journéeTu parles dans le widget, l'IA te répond avec la voix et se base sur tes documents.
Prompt Claude Code · J2
Ajoute deux fonctionnalités au projet :

1. Agent voix :
- Bouton micro dans le widget qui utilise la Web Speech API (lang: "fr-FR") pour transcrire la voix du visiteur en texte.
- Le texte est envoyé à /api/chat comme un message normal.
- La réponse de Claude est convertie en audio via l'API ElevenLabs (modèle Turbo v2, voix française) et jouée automatiquement dans le widget.
- Indicateur visuel pendant l'écoute et la synthèse.

2. Base de connaissances :
- Page /dashboard/knowledge : upload de fichiers PDF, Word, CSV (Supabase Storage).
- À l'upload, découpe chaque document en chunks de ~1 000 tokens.
- Stocke les chunks + leurs embeddings dans une table knowledge_chunks avec pgvector.
- Dans /api/chat, avant d'appeler Claude, cherche les 5 chunks les plus proches du message et injecte-les dans le contexte système.
- Affiche les sources utilisées sous chaque réponse.
J3

Collecte de données + dashboard

  • Extraction structurée en fin de conversation.
  • Score de qualité automatique.
  • Dashboard complet avec fiches et filtres.
  • Personnalisation de l'agent.
Fin de journéeChaque conversation génère une fiche contact exploitable, visible dans le dashboard.
Prompt Claude Code · J3
Ajoute au projet :

1. Collecte de données :
- À la fin de chaque conversation (quand le visiteur part ou après 2 min d'inactivité), appelle Claude avec l'historique pour extraire un JSON structuré : {name, email, phone, need, sentiment, quality_score}.
- Table contacts (id, agent_id, conversation_id, data JSON, score, created_at).
- Le score quality_score (0-100) évalue si la demande a été résolue.

2. Dashboard /dashboard :
- Page /dashboard/conversations : liste des conversations avec filtres (date, score, statut), clic pour voir le détail.
- Page /dashboard/contacts : fiches contact extraites, recherche, export CSV.
- Page /dashboard/settings : personnalisation de l'agent (nom, prompt système, avatar upload, couleurs du widget en JSON).
- Stats en haut : conversations aujourd'hui, score moyen, contacts collectés.
J4

Comptes + paiement

  • Auth par lien magique (Supabase).
  • Stripe Checkout pour le plan Pro.
  • Quota gratuit et gestion des limites.
Fin de journéeUn utilisateur s'inscrit, teste gratuitement, et peut passer en Pro.
Prompt Claude Code · J4
Intègre l'authentification et le paiement :

1. Auth Supabase :
- Connexion par lien magique (email).
- Middleware qui protège les routes /dashboard/*.
- Table profiles (id, email, plan, stripe_customer_id, created_at).

2. Stripe :

3. Quotas (vérifiés côté serveur) :
- Gratuit : 1 agent, 50 conversations texte/mois, pas de voix, badge "Propulsé par [Nom]".
- Pro : agents illimités, voix, base de connaissances, export CSV, widget sans badge.
- Affiche un compteur dans le dashboard et un message dans le widget quand le quota est atteint.

Les risques à connaître

Le coût de la voixElevenLabs facture ~0,01 € par réponse vocale. Le quota gratuit (texte uniquement) protège ta marge. Surveille ta facture dès la première semaine.
La qualité des réponses IAL'agent peut se tromper ou halluciner. Prévois un disclaimer visible et un bouton « Parler à un humain » pour les cas critiques.
La concurrence existeCrisp, Intercom, et Embage eux-mêmes. Ton avantage n'est pas la technique : c'est le prix (19 € vs 95 €+), la voix française, et le positionnement TPE/PME.
