Recrée Popform seul, en 5 jours

Popform détecte les champs d'un contrat PDF grâce à l'IA, envoie un lien de signature et gère un mini CRM. Voici le plan pour construire ta propre version française, pensée pour les indépendants, avec Claude Code.

Traction
Clients à 11 $/mois
Source
BetaList + G2
Build estimé
5 jours
Difficulté
3 / 5

Pourquoi c'est un bon pari

  • Un besoin universel. Tout freelance, consultant ou micro-entreprise signe des contrats. La plupart jonglent encore entre Word, PDF et le scanner du client.
  • Une demande prouvée. Popform est référencé sur G2, BetaList et plusieurs annuaires, avec des clients payants à 11 $/mois et des signatures illimitées.
  • Pas d'équivalent IA en France. Yousign (Caen, 280 000 utilisateurs) et Docage (Normandie) existent, mais aucun n'offre la détection automatique de champs par IA à prix indie.
  • Techniquement simple. Aucun modèle à entraîner : Claude API (vision) détecte les champs d'un PDF, pdf-lib les intègre, et Supabase stocke le tout.
Ton angle de différenciation

La version française, conforme eIDAS, à 9 €/mois. L'IA qui prépare ton contrat à ta place. Cible : les indépendants et freelances qui veulent arrêter d'imprimer pour signer.

Le MVP

Cinq fonctionnalités, pas une de plus pour la première version.

MVP

Upload + détection IA

Upload un PDF, Claude API détecte les champs (nom, date, signature) et les place sur le document.

MVP

Éditeur de champs

Drag-and-drop pour ajuster les champs détectés. Types : texte, date, signature manuscrite, checkbox.

MVP

Signature par lien

Un lien unique envoyé par email. Le signataire remplit et signe dans le navigateur, sans compte.

MVP

PDF signé + preuve

La signature est intégrée au PDF final. Certificat simple (hash + timestamp + IP) envoyé aux deux parties.

MVP

Mini CRM

Liste des contrats, statut (en attente / signé / expiré), rappels automatiques par email.

  • Hors V1 : modèles de contrats prêts à l'emploi, marque blanche, API, signature avancée eIDAS.

Le plan jour par jour

Chaque jour a son prompt prêt à coller dans Claude Code. Lance-le dans un dossier vide, puis relis et teste avant de passer au suivant.

J1

Upload + détection IA des champs

  • Créer le projet Next.js et la page d'upload.
  • Convertir le PDF en images (page par page).
  • Envoyer à Claude API (vision) pour détecter les champs.
  • Afficher les suggestions superposées sur le document.
Fin de journéeTu uploades un PDF et tu vois les champs détectés par l'IA apparaître dessus.
Prompt Claude Code · J1
Crée une application Next.js (App Router, TypeScript, Tailwind), interface en français.
Page /upload : l'utilisateur choisit un fichier PDF.
Route /api/detect : convertis chaque page du PDF en image PNG (avec pdf-to-img ou pdfjs-dist), envoie chaque image à l'API Claude (claude-sonnet-5-5, vision) avec ce prompt système :
"Analyse cette page de contrat. Retourne un JSON avec les zones détectées : pour chaque champ, son type (text, date, signature, checkbox), sa position (x, y, width, height en pourcentage de la page), et un libellé suggéré."
Affiche le PDF avec react-pdf et superpose les champs détectés en position absolue.
Ajoute un fichier .env.example avec ANTHROPIC_API_KEY.
J2

Éditeur de champs + signature canvas

  • Drag-and-drop pour déplacer et redimensionner les champs.
  • Ajout/suppression manuelle de champs.
  • Canvas HTML5 pour la signature manuscrite.
  • Intégration dans le PDF final avec pdf-lib.
Fin de journéeTu ajustes les champs, tu signes à la souris, et tu obtiens un PDF avec ta signature intégrée.
Prompt Claude Code · J2
Ajoute un éditeur de champs sur la page de prévisualisation du PDF :
- Chaque champ détecté est un élément draggable (utilise @dnd-kit/core).
- On peut redimensionner, supprimer ou ajouter manuellement un champ.
- Le champ "signature" ouvre un canvas HTML5 (fond transparent, trait noir, épaisseur 2px).
- Bouton "Générer le PDF" : utilise pdf-lib pour intégrer les valeurs des champs et l'image de signature aux bonnes coordonnées dans le PDF original.
- Télécharge le PDF résultat.
Gère la correspondance entre les positions en pourcentage (affichage) et les points PDF (pdf-lib).
J3

Envoi et signature par lien

  • Connexion utilisateur avec Supabase (lien magique).
  • Sauvegarde du contrat + champs en base.
  • Génération d'un lien de signature unique.
  • Page publique de signature (sans compte).
Fin de journéeTu envoies un lien, le client signe sans compte, et tu reçois le PDF signé par email.
Prompt Claude Code · J3
Ajoute Supabase au projet :
- Auth par lien magique (email).
- Table contracts (id, user_id, title, pdf_url, fields en JSON, status, token, created_at, signed_at) avec RLS.
- Stockage du PDF original dans Supabase Storage (bucket "contracts", privé).
- Bouton "Envoyer pour signature" : génère un token unique, sauvegarde le contrat, envoie un email (Resend) avec le lien /sign/[token].
- Page /sign/[token] (publique) : affiche le PDF et les champs à remplir. Le signataire remplit, signe, valide.
- À la validation : génère le PDF signé (pdf-lib), stocke-le, met à jour le statut, envoie le PDF signé par email aux deux parties.
- Ajoute un hash SHA-256 du PDF signé + timestamp + IP comme certificat de preuve simple.
Donne-moi le SQL de migration.
J4

CRM + paiement

  • Dashboard avec liste des contrats et statuts.
  • Rappels automatiques par email.
  • Abonnement Stripe à 9 €/mois.
  • Quota gratuit : 3 contrats/mois.
Fin de journéeUn utilisateur voit ses contrats, reçoit des rappels, et peut passer Pro pour des contrats illimités.
Prompt Claude Code · J4
Ajoute le dashboard et Stripe :
- Page /dashboard : liste des contrats avec colonnes Titre, Destinataire, Statut (badge couleur), Date. Filtres par statut.
- Rappels automatiques : un cron (Vercel Cron ou pg_cron) envoie un email de rappel aux contrats "en attente" depuis plus de 3 jours.
- Stripe Checkout pour un abonnement "Pro" à 9 €/mois.
- Webhook /api/stripe/webhook pour mettre à jour le statut (free/pro) dans Supabase.
- Quota : max 3 contrats/mois en gratuit, vérifié côté serveur. Pro = illimité.
- Portail client Stripe (/api/stripe/portal) pour gérer l'abonnement.
J5

Landing page et mise en ligne

  • Page d'accueil qui vend le produit.
  • Pages légales et conformité eIDAS.
  • Déploiement sur Vercel.
Fin de journéeLe produit est en ligne, prêt à recevoir ses premiers utilisateurs.
Prompt Claude Code · J5
Crée la page d'accueil en français :
- Titre accrocheur : "Tes contrats signés par l'IA, en un clic."
- Démo animée (GIF ou vidéo courte montrant l'upload → détection → signature).
- 3 bénéfices : détection IA, signature sans compte, CRM intégré.
- Grille tarifaire : Gratuit (3 contrats/mois) / Pro 9 €/mois (illimité).
- FAQ centrée sur eIDAS, la valeur légale de la signature simple, et le RGPD.
- Mentions légales et Politique de confidentialité (modèles à compléter).
- Métadonnées SEO, Open Graph.
- Prépare le déploiement Vercel : liste les variables d'environnement (ANTHROPIC_API_KEY, SUPABASE_URL, SUPABASE_ANON_KEY, STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, RESEND_API_KEY) et les réglages webhook Stripe.

Les risques à connaître

La valeur légaleLa signature électronique simple (SES) est valide pour les actes courants en France et en UE (eIDAS). Elle ne convient pas pour les actes notariés ou les marchés publics. Précise-le dans tes CGU.
Yousign et DocuSign existentTon avantage n'est pas la technique, c'est le prix (9 € vs 15-25 €), l'IA (détection auto) et le positionnement freelance/micro-entreprise.
Le coût de l'API Claude (vision)Chaque détection envoie les pages du PDF à Claude. Limite le nombre de pages analysées (ex. 10 pages max) et surveille ta facture.
