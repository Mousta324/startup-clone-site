Recrée Onepin seul, en 4 jours

Onepin est un agent IA de voix off qui corrige automatiquement la prononciation des noms propres, prix et dates avant de générer l'audio. Voici le plan pour construire ta propre version, pensée pour le marché francophone, avec Claude Code.

Pourquoi c'est un bon pari

  • Une douleur universelle. Quiconque utilise une voix off IA connaît le problème : les noms propres sont écorchés, les prix lus n'importe comment, les dates mal formatées. On passe du temps à ruser phonétiquement, segment par segment.
  • Une demande prouvée aujourd'hui même. 242 upvotes et la 1re place de Product Hunt le jour du lancement. Onepin affirme travailler avec HeyGen, Hyundai et Johns Hopkins (chiffres du créateur, non vérifiés de façon indépendante).
  • Aucun concurrent français sur cet angle précis. ElevenLabs, Murf, Lovo et Fliki proposent des voix françaises mais aucun n'auto-détecte ni auto-corrige les noms, prix et dates. ElevenLabs offre un dictionnaire de prononciation mais il est 100 % manuel.
  • Techniquement simple. Pas de modèle à entraîner : un appel Claude pour détecter et réécrire, un appel ElevenLabs pour générer l'audio.
Ton angle de différenciation

La version française qui comprend les noms francophones, les prix en euros et les dates au format européen. Hébergement en UE, conformité RGPD. Cible : le créateur de contenu solo qui a besoin de 5 voix off par semaine, pas de 5 000.

Le MVP

Cinq fonctionnalités, pas une de plus pour la première version.

MVP

Éditeur de texte intelligent

Colle ton script. L'app détecte et surligne les noms propres, prix, dates et abréviations via Claude.

MVP

Correction automatique

Chaque élément détecté est réécrit en texte phonétiquement correct pour le moteur TTS.

MVP

Génération audio

Le texte corrigé est envoyé à ElevenLabs en streaming. Choix de voix et de vitesse.

MVP

Score de qualité

Un agent Claude transcrit le rendu et compare à l'original. Note par segment : correct, douteux, à refaire.

MVP

Dashboard et historique

Liste des voix off générées, replay, re-génération d'un segment seul.

  • Hors V1 : multi-langues, clonage de voix, intégration éditeur vidéo, API publique, batch processing.

Le plan jour par jour

Chaque jour a son prompt prêt à coller dans Claude Code. Lance-le dans un dossier vide, puis relis et teste avant de passer au suivant.

J1

L'éditeur et la correction

  • Créer le projet Next.js et l'éditeur de texte.
  • Détection des noms, prix, dates via Claude API.
  • Affichage du texte corrigé avec surlignage des modifications.
Fin de journéeTu colles un script et les noms, prix et dates sont surlignés et corrigés automatiquement.
Prompt Claude Code · J1
Crée une application Next.js (App Router, TypeScript, Tailwind), interface en français.
Page principale : un éditeur de texte (textarea) où l'utilisateur colle son script de voix off.
À la soumission, appelle une route /api/correct qui envoie le texte à l'API Claude avec ce prompt système : « Tu es un correcteur de prononciation pour la synthèse vocale française. Analyse le texte et renvoie un JSON avec : le texte corrigé (noms propres en phonétique naturelle, prix en toutes lettres, dates en format parlé, abréviations développées), et un tableau des modifications (position, original, corrigé, raison). »
Affiche le texte corrigé avec les modifications surlignées en vert. L'utilisateur peut accepter ou rejeter chaque correction individuellement.
Ajoute un fichier .env.example et un README.
J2

La génération audio

  • Intégration ElevenLabs API en streaming.
  • Choix de voix et vitesse de lecture.
  • Historique sauvegardé en base Supabase.
Fin de journéeTu génères un audio propre à partir de ton script corrigé, avec la voix de ton choix.
Prompt Claude Code · J2
Ajoute la génération audio au projet :
- Route /api/generate qui prend le texte corrigé et l'envoie à l'API ElevenLabs (SDK officiel, streaming).
- Sélecteur de voix (liste les voix françaises disponibles via l'API) et curseur de vitesse.
- Lecteur audio intégré avec visualisation de la forme d'onde.
- Bouton de téléchargement MP3.
Ajoute Supabase :
- Auth par lien magique.
- Table voiceovers (id, user_id, texte_original, texte_corrige, audio_url, voix, created_at) avec Row Level Security.
- Page /historique pour retrouver ses voix off.
Donne-moi le SQL de migration.
J3

Score de qualité et re-génération

  • Transcription du rendu audio et comparaison avec l'original.
  • Note par segment avec bouton re-générer.
  • Quota gratuit : 5 voix off par jour.
Fin de journéeChaque audio est noté segment par segment, et tu corriges les passages faibles en un clic.
Prompt Claude Code · J3
Ajoute le scoring de qualité :
- Route /api/score qui découpe le texte corrigé en segments (par phrase), transcrit l'audio généré (utilise l'API Whisper d'OpenAI ou la transcription ElevenLabs), et envoie à Claude un prompt de comparaison segment par segment.
- Claude renvoie pour chaque segment : score (correct / douteux / à refaire), différence détectée, suggestion.
- Interface : affiche les segments avec un code couleur (vert / orange / rouge) et un bouton « Re-générer ce segment » qui ne re-génère que le passage concerné.
- Quota : vérifie côté serveur que les comptes gratuits ne dépassent pas 5 voix off par jour.
- Page /reglages : l'utilisateur peut entrer sa propre clé ElevenLabs. Si présente, le quota ne s'applique pas.
J4

Paiement et mise en ligne

  • Abonnement Pro avec Stripe.
  • Landing page avec démo interactive.
  • Déploiement sur Vercel.
Fin de journéeLe produit est en ligne, prêt à être présenté et à vendre.
Prompt Claude Code · J4
Intègre Stripe :
- Stripe Checkout pour un abonnement mensuel « Pro » à 14 €.
- Webhook qui met à jour le statut (free / pro) dans Supabase, y compris à la résiliation.
- Portail client Stripe pour gérer l'abonnement.
Fonctions Pro : voix off illimitées, toutes les voix, export WAV, score de qualité, dictionnaire de prononciation personnel (mots que l'utilisateur ajoute avec leur prononciation).
Crée la page d'accueil en français : titre accrocheur, démo interactive (champ de texte avec correction en direct), 3 bénéfices, grille tarifaire (Gratuit / Pro 14 € / Tes clés API), FAQ sur la confidentialité et le RGPD.
Ajoute les pages Mentions légales et Politique de confidentialité, les métadonnées SEO, et la liste des variables d'environnement pour Vercel.

Les risques à connaître

Le coût des APIChaque voix off appelle Claude (correction) + ElevenLabs (audio). Le quota gratuit et l'option « tes clés » protègent ta marge ; surveille ta facture dès la première semaine.
La qualité de la correctionLes noms très rares ou les termes techniques pointus peuvent être mal corrigés. Le dictionnaire personnel et la validation humaine avant génération limitent le risque.
Onepin a une avance technique4 millions de mots dans son dictionnaire, 30+ moteurs TTS, certification SOC 2. Ton avantage n'est pas la technique, c'est la simplicité et le positionnement français.
