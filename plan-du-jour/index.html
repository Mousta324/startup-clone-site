Recrée Dedica seul, en 4 jours

Dedica scanne un site web comme le ferait un agent IA (Muse, Instinct, GrokBot…), repère ce qui bloque et donne un score sur 100. Voici le plan pour construire ta version française, avec Claude Code.

Pourquoi c'est un bon pari

  • Le timing est parfait. Apple, Google et OpenAI ont tous lancé des agents commerciaux grand public en 2026. Chaque site qui n'est pas « agent-ready » perd des clients sans le savoir.
  • Une demande prouvée. 228 upvotes et #1 Product of the Day sur Product Hunt le 28 octobre 2026, avec 78 commentaires. Le créateur a observé un agent IA échouer sur un simple formulaire SaaS.
  • Aucun concurrent en français. Cloudflare a lancé isitagentready.com (basique, en anglais). Aucun outil francophone ne propose un audit complet avec fiches de correction. Le créneau est libre.
  • Techniquement simple. Aucun modèle à entraîner : un crawler headless qui vérifie des standards (robots.txt, llms.txt, Schema.org, HTML sémantique) et génère un rapport.
Ton angle de différenciation

La version française et actionnable : interface en français, rapport avec des fiches de correction prêtes à coller dans Claude Code, angle RGPD (données scannées non conservées), et un badge « Agent-Ready » à afficher sur son site. Cible : les agences web, les freelances et les SaaS francophones.

Le MVP

Cinq fonctionnalités, pas une de plus pour la première version.

MVP

Scan d'URL en un clic

Entre une URL, lance 80+ vérifications automatiques en moins d'une minute. Pas de compte requis.

MVP

Score sur 100 + 4 sous-scores

Découverte, Accès, Utilisabilité, Paiement. Chaque catégorie avec un code couleur vert/orange/rouge.

MVP

Rapport détaillé en français

Chaque vérification expliquée avec sa sévérité et une recommandation de correction en une phrase.

MVP

Export PDF

Génère un rapport propre à envoyer à un client ou un prestataire. Idéal pour les agences.

MVP

API publique

Un endpoint JSON pour intégrer l'audit dans un pipeline CI/CD ou un outil interne.

  • Hors V1 : monitoring continu, badge dynamique, serveur MCP, intégration Slack, rapport en marque blanche.

Le plan jour par jour

Chaque jour a son prompt prêt à coller dans Claude Code. Lance-le dans un dossier vide, puis relis et teste avant de passer au suivant.

J1

Le scanner de base

  • Créer le projet Next.js et la page d'accueil avec champ URL.
  • Route API qui lance Playwright sur l'URL cible.
  • 10 premiers checks : robots.txt, llms.txt, balises meta, Schema.org, titre, headings, images alt, sitemap.xml, HTTPS, viewport.
Fin de journéeTu entres une URL et tu vois un score global avec les 10 premiers résultats.
Prompt Claude Code · J1
Crée une application Next.js (App Router, TypeScript, Tailwind), interface en français.
Page d'accueil : un champ URL centré avec un bouton « Scanner ».
À l'envoi, appelle une route /api/scan qui :
1. Lance Playwright (headless Chromium) sur l'URL.
2. Vérifie 10 points : présence de robots.txt (et si les bots IA sont autorisés), llms.txt, balises meta (title, description, og:*), Schema.org (JSON-LD), structure des headings (h1-h3), attributs alt sur les images, sitemap.xml, HTTPS actif, balise viewport.
3. Renvoie un JSON : score global sur 100, et pour chaque check : nom, statut (ok/warning/fail), détail en français.
Page de résultats : affiche le score en gros avec un code couleur (vert > 70, orange 40-70, rouge < 40), puis la liste des checks avec des icônes.
Ajoute un fichier .env.example et un README.
J2

Checks complets et catégories

  • Ajouter les 4 catégories : Découverte, Accès, Utilisabilité, Paiement.
  • 60+ checks supplémentaires.
  • Sous-score par catégorie avec code couleur.
Fin de journéeLe scan couvre 70+ vérifications réparties en 4 catégories avec sous-scores.
Prompt Claude Code · J2
Ajoute des checks au scanner, organisés en 4 catégories :
— Découverte : robots.txt permissif pour les bots IA, llms.txt, sitemap.xml, liens internes cohérents, Schema.org complet, Open Graph, canonical.
— Accès : HTTPS, temps de chargement < 3 s, pas de blocage JS obligatoire pour le contenu principal, headers HTTP (X-Frame-Options, CSP), CORS.
— Utilisabilité : HTML sémantique (nav, main, article, section), formulaires avec labels et autocomplete, boutons avec texte visible, skip-to-content, contraste suffisant, responsive (viewport).
— Paiement : formulaires de paiement accessibles, prix visibles en texte (pas en image), boutons d'action clairs.
Affiche un sous-score par catégorie sur la page de résultats.
Pour chaque check en échec, affiche une recommandation de correction en une phrase en français.
J3

Comptes, historique et export

  • Connexion par lien magique avec Supabase.
  • Historique des scans par utilisateur.
  • Export PDF du rapport.
Fin de journéeUn utilisateur peut créer un compte, retrouver ses scans passés et exporter un PDF.
Prompt Claude Code · J3
Ajoute Supabase au projet :
- Authentification par lien magique (email).
- Table scans (id, user_id, url, score, results en JSON, created_at) avec Row Level Security.
- Sauvegarde automatique de chaque scan pour les utilisateurs connectés.
- Page /historique listant les scans passés avec l'URL, le score et la date, cliquables pour revoir le détail.
- Bouton « Exporter PDF » sur la page de résultats : génère un PDF propre avec le score, les sous-scores, et la liste des checks (utilise @react-pdf/renderer ou html2pdf).
- Mode comparaison : sur /historique, sélectionne deux scans de la même URL pour voir l'évolution.
Quota : 3 scans/jour pour les comptes gratuits, vérifié côté serveur.
J4

Landing, API et mise en ligne

  • Landing page en français.
  • API publique documentée.
  • Paiement Stripe et déploiement.
Fin de journéeLe produit est en ligne, prêt à être présenté.
Prompt Claude Code · J4
Crée la page d'accueil en français :
- Titre accrocheur : « Ton site est-il prêt pour les agents IA ? »
- Démo : le champ de scan directement sur la landing.
- 3 bénéfices visuels : Découvre tes failles, Corrige en un clic, Rassure tes clients.
- Grille tarifaire : Gratuit (3 scans/jour) / Pro 9 €/mois (illimité, PDF, historique, badge) / API (0,05 €/scan).
- FAQ : Qu'est-ce qu'un agent IA ? Mes données sont-elles conservées ? (Non.)
Intègre Stripe Checkout pour l'abonnement Pro avec webhook.
Ajoute une route /api/v1/scan documentée (entrée : URL, sortie : JSON score + checks) avec rate limiting.
Prépare le déploiement sur Vercel : variables d'environnement, mentions légales, SEO.

Les risques à connaître

Le crawl a ses limitesCertains sites bloquent les headless browsers. Playwright avec des headers réalistes et un user-agent d'agent IA contourne la plupart des cas, mais pas tous.
Les standards évoluent vitellms.txt, MCP, agent skills : ces normes changent tous les mois. Prévoir une architecture modulaire pour ajouter des checks facilement.
La concurrence arriveraCloudflare et les outils SEO (Semrush, Ahrefs) ajoutent déjà des modules agent-readiness. Ton avantage : le français, la correction guidée, et la rapidité d'exécution.
