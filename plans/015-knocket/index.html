Recrée Knocket seul, en 5 jours

Knocket est un chat gratuit et illimité pour ton site, avec réponse depuis Telegram et une page de contact partageable. Voici le plan pour construire ta version française, avec un agent IA intégré, en utilisant Claude Code.

Pourquoi c'est un bon pari

  • Un problème universel. Tout indépendant, artisan ou micro-entreprise a un site mais pas de chat. Les visiteurs partent sans réponse.
  • Le gratuit total est disruptif. Intercom coûte 39 $/mois, LiveChat 20 $, même Crisp limite son offre gratuite. Knocket est 100 % gratuit sans badge ni limite — et ça a suffi pour atteindre le #2 Product Hunt.
  • Pas de version française gratuite. Crisp (Nantes) est le leader FR, mais son plan gratuit est limité à 2 opérateurs et n'inclut pas l'IA. Tawk.to est canadien, badge obligatoire sauf paiement.
  • Techniquement accessible. Un widget JavaScript, des WebSockets pour le temps réel, l'API Telegram Bot pour les notifications. Pas de modèle IA à entraîner.
Ton angle de différenciation

La version française, gratuite et dopée à l'IA : interface et support en français, données hébergées en UE (Supabase région Francfort), et un agent IA (Claude) qui répond aux visiteurs en ton absence — ce que Crisp facture 95 €/mois.

Le MVP

Cinq fonctionnalités, pas une de plus pour la première version.

MVP

Widget de chat en direct

Un script JS à coller sur n'importe quel site. Le visiteur écrit, le message arrive en temps réel dans ta boîte.

MVP

Page de contact autonome

Un lien partageable avec chat intégré, liens sociaux et prise de rendez-vous. Idéal pour un link-in-bio.

MVP

Notifications Telegram

Chaque message déclenche une notification Telegram. Tu réponds directement depuis ton téléphone.

MVP

Boîte de réception unifiée

Un dashboard web qui centralise toutes les conversations de tous tes sites.

OPT

Agent IA de réponse

Un chatbot alimenté par Claude qui répond aux questions fréquentes quand tu es absent. C'est le levier payant.

  • Hors V1 : intégrations WhatsApp et Instagram, application mobile native, multi-opérateurs, analytics avancés.

Le plan jour par jour

Chaque jour a son prompt prêt à coller dans Claude Code. Lance-le dans un dossier vide, puis relis et teste avant de passer au suivant.

J1

Le widget de chat + le backend

  • Créer le projet Next.js + Supabase.
  • Tables conversations et messages avec Row Level Security.
  • Widget JS (iframe) qui ouvre un chat en bas à droite.
  • Supabase Realtime pour le temps réel.
Fin de journéeLe widget s'affiche sur une page test et les messages arrivent dans Supabase en temps réel.
Prompt Claude Code · J1
Crée une application Next.js (App Router, TypeScript, Tailwind), interface en français.
Intègre Supabase avec les tables : sites (id, user_id, name, domain), conversations (id, site_id, visitor_name, status, created_at), messages (id, conversation_id, sender, content, created_at).
Active Row Level Security : chaque utilisateur ne voit que ses propres sites et conversations.
Crée un widget de chat en JavaScript vanille (pas de framework) qui s'intègre via un script tag. Le widget affiche une bulle en bas à droite, s'ouvre en iframe, et envoie les messages à une API route /api/messages.
Utilise Supabase Realtime pour que les messages apparaissent instantanément des deux côtés.
Teste en local avec deux onglets : un pour le visiteur (widget), un pour le dashboard.
J2

Page de contact + Telegram

  • Page de contact dynamique /c/[slug].
  • Bot Telegram pour les notifications et réponses.
  • Inscription par lien magique (Supabase Auth).
Fin de journéeUn visiteur écrit sur la page de contact, le message arrive dans Telegram, tu réponds depuis Telegram et le visiteur voit ta réponse.
Prompt Claude Code · J2
Ajoute au projet :
1. Page de contact dynamique /c/[slug] : chat intégré, avatar, description, liens sociaux configurables, bouton de prise de rendez-vous (lien Calendly).
2. Authentification par lien magique avec Supabase Auth. Après inscription, l'utilisateur configure son premier site et sa page de contact.
3. Bot Telegram : crée un bot via l'API Telegram Bot. Quand un nouveau message arrive, envoie une notification Telegram avec le nom du visiteur et le contenu. Quand l'utilisateur répond dans Telegram, le message est routé vers la bonne conversation via un webhook /api/telegram.
4. Table telegram_links (user_id, chat_id) pour lier un compte utilisateur à son Telegram.
Donne-moi le SQL de migration Supabase.
J3

Boîte de réception + agent IA

  • Dashboard /inbox avec liste des conversations.
  • Réponse en direct depuis le dashboard.
  • Agent IA optionnel (Claude Haiku).
Fin de journéeLe dashboard affiche toutes les conversations, tu réponds en direct ou l'IA répond à ta place.
Prompt Claude Code · J3
Ajoute au projet :
1. Page /inbox : liste des conversations (ouvertes, résolues) avec recherche et filtres. Clic sur une conversation pour voir les messages et répondre en temps réel.
2. Indicateurs : nombre de conversations ouvertes, temps de réponse moyen, messages non lus.
3. Agent IA : un toggle par site « Activer l'agent IA ». Quand activé, si aucune réponse humaine en 30 secondes, Claude Haiku répond automatiquement en utilisant un prompt système personnalisable (description du business, FAQ). Utilise l'API Anthropic avec le modèle claude-haiku-4-5-20251001.
4. Les réponses IA sont marquées comme telles dans la conversation.
J4

Monétisation + landing page

  • Stripe Checkout pour l'abonnement Pro.
  • Landing page en français.
  • Restriction des fonctionnalités payantes.
Fin de journéeUn utilisateur peut s'inscrire, activer le chat gratuit, et passer en Pro pour débloquer l'agent IA.
Prompt Claude Code · J4
Intègre Stripe :
- Stripe Checkout pour un abonnement « Pro » à 12 €/mois.
- Webhook qui met à jour le statut (free / pro) dans Supabase.
- Portail client Stripe pour gérer l'abonnement.
Fonctions réservées au Pro : agent IA, widget sans badge, personnalisation des couleurs, sites illimités.
Crée la landing page en français : titre accrocheur (« Le chat de site gratuit et illimité »), démo interactive du widget, 3 avantages (gratuit, Telegram, IA), grille tarifaire (Gratuit / Pro 12 € / Équipe 29 €), FAQ, témoignages placeholder.
Ajoute les métadonnées SEO et les images Open Graph.
J5

Finitions et mise en ligne

  • Script d'installation en un clic.
  • Pages légales et documentation.
  • Tests mobiles et déploiement.
Fin de journéeLe produit est en ligne, prêt à être utilisé et partagé.
Prompt Claude Code · J5
Finalise le projet :
1. Page /install avec le snippet à copier-coller, un guide pas à pas, et un bouton « Tester sur cette page » qui affiche le widget en direct.
2. Pages Mentions légales et Politique de confidentialité (modèles conformes RGPD à compléter).
3. Tests complets : responsive mobile, widget sur différents navigateurs, Telegram aller-retour, paiement Stripe en mode test.
4. Corrige les bugs trouvés.
5. Prépare le déploiement Vercel : liste toutes les variables d'environnement (SUPABASE_URL, SUPABASE_ANON_KEY, TELEGRAM_BOT_TOKEN, STRIPE_SECRET_KEY, ANTHROPIC_API_KEY) et les réglages webhook Stripe en production.

Les risques à connaître

Le marché est bondéCrisp, Tawk.to, Intercom, Tidio, Chatwoot. Ton avantage n'est pas la technique, c'est le positionnement : gratuit + français + IA intégrée.
Le gratuit coûte cher à tenirSi le trafic explose, les coûts Supabase et Vercel montent. Surveille les limites des plans gratuits et prévois un palier payant dès le départ.
Le coût de l'IAClaude Haiku coûte ~0,001 $ par message, mais 10 000 messages/jour = 300 $/mois. Réserve l'IA aux comptes Pro pour protéger ta marge.
