Recrée Famulor seul, en 5 jours

Famulor est une IA qui décroche tes appels, prend les rendez-vous et relance par WhatsApp. Voici le plan pour construire ta propre version, pensée pour les micro-entreprises françaises, avec Claude Code.

Pourquoi c'est un bon pari

  • Un besoin universel. Artisans, coachs, thérapeutes, e-commerçants : quand le téléphone sonne et que personne ne décroche, le prospect appelle un concurrent. Un appel manqué sur deux ne donne jamais lieu à un rappel.
  • Une demande prouvée. 227 upvotes et #4 sur Product Hunt le 2 octobre 2026. C'est le 4e lancement de l'équipe depuis juillet 2025 — un produit itéré, pas un side-project.
  • Des concurrents FR chers. Eliocall (~30 €/mois), Fonio (59 €/mois), Limova (79 €/mois) existent mais sont des services managés. Tu ne possèdes rien, tu ne personnalises rien.
  • Le timing est parfait. ElevenLabs v4 (lancé le même jour), Twilio Voice et Claude rendent un agent vocal de qualité accessible à un développeur seul pour la première fois.
Ton angle de différenciation

La version à toi : pas d'abonnement à un service tiers, tu possèdes le code et les données. Tu cibles les micro-entreprises françaises (artisans, indépendants, cabinets) avec un prix imbattable — le coût réel d'un appel IA tombe sous 0,02 € quand tu possèdes la stack.

Le plan jour par jour

Chaque jour a son prompt prêt à coller dans Claude Code. Lance-le dans un dossier vide, puis relis et teste avant de passer au suivant.

J1

L'agent vocal de base

  • Créer le projet Next.js + Tailwind.
  • Acheter un numéro Twilio, configurer le webhook entrant.
  • Route /api/call : Twilio transcrit → Claude répond → TTS renvoie la réponse vocale.
  • Tester en local avec ngrok.
Fin de journéeTu appelles ton numéro, l'IA décroche et discute avec toi.
Prompt Claude Code · J1
Crée une application Next.js (App Router, TypeScript, Tailwind).
Intègre Twilio Voice : achète un numéro via l'API, configure un webhook POST /api/call/incoming.
Quand un appel arrive :
1. Twilio transcrit la voix du caller en temps réel (speech recognition).
2. Envoie la transcription à l'API Claude (modèle claude-sonnet-5) avec un system prompt configurable (ex. "Tu es l'assistant du cabinet dentaire Martin, tu prends les rendez-vous").
3. La réponse de Claude est convertie en voix via Twilio <Say> ou ElevenLabs, et renvoyée au caller.
Gère le tour-par-tour : le caller parle, l'IA répond, et ainsi de suite jusqu'à ce que le caller raccroche.
Sauvegarde chaque appel (caller, durée, transcription complète) dans une table Supabase.
Ajoute un fichier .env.example avec toutes les clés nécessaires et un README pour lancer le projet.
J2

L'éditeur de flux visuel

  • Installer React Flow et créer les types de blocs.
  • Blocs : Accueil, Question, Condition (si/sinon), Réponse, Transfert, Fin.
  • Sauvegarde du flow en JSON dans Supabase.
  • L'agent vocal lit le flow et adapte la conversation.
Fin de journéeTu dessines un flux de conversation dans l'interface, et l'IA le suit au téléphone.
Prompt Claude Code · J2
Ajoute un éditeur de flux visuel avec React Flow :
- Page /flows pour créer et éditer des flux de conversation.
- Types de nœuds : Accueil (message d'accueil), Question (l'IA pose une question et attend la réponse), Condition (si la réponse contient X, aller vers Y), Réponse (l'IA dit un texte), Transfert (transférer l'appel à un numéro humain), Fin (raccrocher poliment).
- Chaque nœud a un champ texte éditable et des connecteurs pour les relier.
- Le flow est sauvegardé en JSON dans une table flows (id, user_id, name, nodes, edges, created_at) avec RLS.
- Modifie /api/call/incoming pour charger le flow actif de l'utilisateur et l'exécuter pendant l'appel : Claude reçoit le contexte du nœud courant et fait avancer la conversation selon les connexions.
- Page /flows/[id] pour éditer un flow existant.
J3

Rendez-vous et suivi

  • Google Calendar API : lister les créneaux, proposer, bloquer.
  • L'IA propose les disponibilités pendant l'appel.
  • SMS de confirmation via Twilio.
  • Email récapitulatif via Resend.
Fin de journéeL'IA prend un rendez-vous au téléphone, il apparaît dans ton Google Calendar, et le client reçoit un SMS.
Prompt Claude Code · J3
Intègre la prise de rendez-vous :
- Google Calendar API : OAuth2 pour connecter le calendrier de l'utilisateur. Fonctions : lister les créneaux libres sur les 7 prochains jours, créer un événement avec le nom et le téléphone du caller.
- Ajoute un nœud "Rendez-vous" dans React Flow : quand l'IA atteint ce nœud, elle propose les 3 prochains créneaux libres au caller, confirme le choix et bloque le créneau.
- Après l'appel, envoie un SMS de confirmation au caller via Twilio (numéro, date, heure).
- Envoie aussi un email récapitulatif à l'utilisateur via Resend (résumé de l'appel + rendez-vous pris).
- Page /reglages pour connecter son Google Calendar et configurer les horaires d'ouverture.
J4

Dashboard et comptes

  • Auth Supabase par lien magique.
  • Dashboard avec liste des appels et transcriptions.
  • Métriques : appels reçus, RDV pris, durée moyenne, taux de réponse.
  • Page de configuration du prompt système.
Fin de journéeTu te connectes, tu vois tous les appels, tu configures le comportement de ton IA.
Prompt Claude Code · J4
Ajoute l'authentification et le dashboard :
- Auth Supabase : inscription et connexion par lien magique (email).
- Page /dashboard : liste des appels (date, caller, durée, statut, résumé IA). Clic sur un appel pour voir la transcription complète.
- Métriques en haut : appels reçus aujourd'hui / cette semaine / ce mois, rendez-vous pris, durée moyenne, taux de réponse (appels répondus par l'IA vs manqués).
- Page /reglages : champ texte pour le prompt système de l'IA ("Tu es l'assistant de..."), numéro Twilio associé, horaires d'ouverture, email de notification.
- Toutes les données filtrées par user_id avec RLS Supabase.
- Donne-moi le SQL de migration complet.

Les risques à connaître

La latence vocaleUn échange vocal IA fluide demande < 1 s de latence. Twilio + Claude en streaming + TTS bien configuré y arrive, mais teste avec des conditions réseau réelles avant de lancer.
Le coût par appelTwilio (~0,01 €/min) + Claude (~0,003 €/appel de 2 min) + TTS. Le tier gratuit absorbe le coût d'acquisition ; surveille ta marge dès le premier mois.
La concurrence existeEliocall, Fonio et Famulor lui-même. Ton avantage n'est pas la technique, c'est le prix (tu possèdes la stack) et la personnalisation totale.
La confiance vocaleCertains callers n'aiment pas parler à une IA. Prévois toujours un nœud « Transfert humain » dans le flux.
