Pourquoi c'est un bon pari

  • Un besoin universel. Chaque lancement a besoin d'une vidéo. En 2026, la vidéo est le format roi sur les réseaux, Product Hunt et les landing pages. Mais une vidéo pro coûte 500 à 5 000 € et prend des jours.
  • Une demande prouvée. 430 upvotes et la première place sur Product Hunt le 2 octobre 2026, avec 55 commentaires. Pricing validé à $30/mois.
  • Pas d'alternative FR abordable. PlayPlay (Paris) démarre à ~280 €/mois avec des contrats de 24 mois — pour les grandes entreprises. Rien de simple et accessible pour les indie makers francophones.
  • Le timing est parfait. Remotion.js (React → vidéo) est mature, Claude écrit un script en secondes, ElevenLabs produit une voix naturelle en français. Coût par vidéo : moins de 0,50 €.
Ton angle de différenciation

La version française, simple et 30 fois moins chère : pas de génération IA pixel par pixel (GPU coûteux), mais des templates motion graphics élégants rendus par Remotion. Tu cibles les indie makers, freelances et micro-startups qui n'ont ni le budget PlayPlay ni le temps After Effects.

Formulaire produit

Nom, slogan, 3 features, couleur principale, logo ou capture d'écran. Rien de plus.

MVP

MVP

Téléchargement direct ou lien de partage. Formats 9:16 (Reels/TikTok) et 16:9 (YouTube).

Le plan jour par jour

Chaque jour a son prompt prêt à coller dans Claude Code. Lance-le dans un dossier vide, puis relis et teste avant de passer au suivant.

J1

Le moteur vidéo

  • Créer le projet Next.js + Tailwind + Remotion.
  • Créer 3 compositions vidéo (intro hook, slides features, CTA final).
  • Animations : texte qui apparaît, fond qui glisse, mockup qui entre.
  • Tester le rendu en local avec npx remotion render.
Fin de journéeTu modifies du texte dans le code et tu obtiens un MP4 de 30 secondes avec des animations propres.
Prompt Claude Code · J1
Crée une application Next.js (App Router, TypeScript, Tailwind) avec Remotion intégré.
Crée 3 compositions vidéo Remotion en 1080×1920 (format 9:16) :
1. Intro (3 s) : le nom du produit apparaît en grand avec une animation de scale, puis le slogan glisse depuis le bas, fond avec un dégradé de la couleur principale.
2. Features (3 slides × 3 s) : chaque slide affiche un titre de feature et une description courte, avec une transition de slide horizontal. Icône ou numéro à gauche.
3. CTA (3 s) : "Essaie maintenant" avec le lien du site, animation de pulse sur le bouton.
Les données (nom, slogan, features, couleur, lien) sont dans un fichier data.ts pour le moment.
Ajoute une piste audio placeholder (fichier MP3 vide de 15 s).
Configure le rendu : npx remotion render pour générer un MP4.
README avec les instructions d'installation et de rendu.
J2

Script IA et formulaire

  • Formulaire produit (nom, slogan, 3 features, couleur, logo/capture).
  • Route API Claude pour générer le script vidéo en JSON.
  • Le JSON alimente les compositions Remotion automatiquement.
  • Prévisualisation dans le navigateur avec Remotion Player.
Fin de journéeTu remplis le formulaire, tu vois ta vidéo personnalisée en direct dans le navigateur.
Prompt Claude Code · J2
Ajoute un formulaire et la génération IA :
- Page /create avec un formulaire : nom du produit, slogan (1 ligne), 3 features (titre + description courte chacune), couleur principale (color picker), upload de logo ou capture d'écran.
- Route POST /api/generate-script : envoie les données à l'API Claude (claude-sonnet-5) avec un prompt qui demande un JSON structuré : { hook: string, problem: string, features: [{title, desc}], cta: string }. Le script est en français, ton dynamique.
- Le JSON retourné est passé aux compositions Remotion via les inputProps.
- Intègre le Remotion Player dans la page pour prévisualiser la vidéo en temps réel.
- Bouton "Régénérer le script" pour obtenir une variante.
- Bouton "Modifier le script" qui ouvre un éditeur JSON simple pour ajuster le texte avant rendu.
J3

Voix off et musique

  • ElevenLabs API pour la voix off en français.
  • 3 pistes musicales libres de droits intégrées au projet.
  • Synchronisation du timing voix ↔ scènes.
  • Sous-titres automatiques (le script est déjà du texte).
Fin de journéeLa vidéo a une voix off naturelle en français, de la musique et des sous-titres synchronisés.
Prompt Claude Code · J3
Intègre la voix off et la musique :
- Route POST /api/generate-voice : envoie chaque segment du script à l'API ElevenLabs (voix française, modèle eleven_multilingual_v2). Récupère les fichiers audio MP3.
- Mesure la durée de chaque segment audio et ajuste la durée des compositions Remotion en conséquence (la scène dure aussi longtemps que la voix).
- Ajoute une couche audio dans chaque composition avec le segment voix correspondant.
- Ajoute un sélecteur de musique de fond : 3 pistes libres de droits (upbeat, chill, corporate) stockées dans /public/music. Volume de la musique à 15 % pendant la voix.
- Ajoute des sous-titres animés : le texte du script apparaît mot par mot en bas de l'écran, synchronisé avec l'audio (utilise les timestamps de l'API ElevenLabs si disponibles, sinon découpe proportionnellement).
- Clé API ElevenLabs dans .env.local.
J4

Comptes et templates

  • Auth Supabase par lien magique.
  • Dashboard avec historique des vidéos.
  • 3 templates visuels (Minimaliste, Bold, Dark).
  • Choix du format : 9:16 ou 16:9.
Fin de journéeUn utilisateur crée un compte, choisit son template et génère ses vidéos.
Prompt Claude Code · J4
Ajoute l'authentification et les templates :
- Auth Supabase : connexion par lien magique (email).
- Table videos (id, user_id, product_name, script JSON, template, format, status, video_url, created_at) avec Row Level Security.
- Page /dashboard : liste des vidéos générées (miniature, nom, date, statut). Actions : télécharger, re-générer, supprimer.
- 3 templates Remotion distincts :
  1. Minimaliste : fond blanc, texte noir, accents de couleur. Propre et pro.
  2. Bold : fond couleur vive (la couleur du produit), texte blanc en gras, animations fortes.
  3. Dark : fond #0A0A0F, texte blanc, accents lime #C8FF3D. Style tech/startup.
- Sélecteur de format dans le formulaire : 9:16 (1080×1920, Reels/TikTok) ou 16:9 (1920×1080, YouTube/site).
- Le rendu est lancé en background (file d'attente simple avec statut pending → rendering → done).
- Donne-moi le SQL de migration complet.

Les risques à connaître

Le rendu vidéo prend du tempsRemotion Lambda rend une vidéo de 30 s en 20 à 40 secondes. Acceptable pour un MVP, mais prévois une file d'attente et un indicateur de progression.
Le coût de la voix offElevenLabs facture ~0,30 € par vidéo de 30 s. Avec le tier gratuit (1 vidéo/mois), le coût d'acquisition reste maîtrisé. Surveille ta facture ElevenLabs dès la première semaine.
La concurrence existePexo ($30/mois), Fliki, InVideo, Synthesia. Ton avantage : le prix (9 € vs 30+ $), le français natif, et des templates motion graphics qui ne nécessitent pas de GPU.
La qualité des templatesDes templates moches tuent le produit. Investis du temps sur 3 templates vraiment beaux plutôt que 10 médiocres. Inspire-toi des meilleures vidéos Product Hunt.
