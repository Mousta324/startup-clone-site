Recrée HireKey seul, en 5 jours

HireKey est un copilote IA pour la recherche d'emploi : il analyse ta compatibilité avec un poste, adapte ton CV, simule l'entretien et te coache à l'oral. Voici le plan pour construire ta version française avec Claude Code.

Pourquoi c'est un bon pari

  • Une douleur universelle. Adapter son CV à chaque offre, préparer chaque entretien, relancer — la recherche d'emploi est un job à plein temps que personne n'aime faire.
  • Une demande prouvée. 282 upvotes et #1 sur Product Hunt le jour du lancement. Selon l'APEC (mai 2026), 31 % des cadres en recherche utilisent déjà l'IA pour leur CV et leurs lettres.
  • Pas d'outil français complet. JeTrichePas coache l'entretien, AttractiveCV fait le CV, JobCopilot automatise les candidatures — mais aucun ne fait les trois à la fois, en français, avec du coaching vocal.
  • Techniquement accessible. Aucun modèle à entraîner : tout passe par l'API Claude (excellent en français) et la Web Speech API (gratuite, native dans Chrome).
Ton angle de différenciation

La version française et tout-en-un : CV au format français (pas de resume US), simulation d'entretien « à la française », coaching vocal en français, données hébergées en Europe (RGPD), et intégration des codes du marché français (CDI, alternance, convention collective).

Le MVP

Cinq fonctionnalités, pas une de plus pour la première version.

MVP

Analyse de compatibilité

Colle une offre + ton CV. L'IA compare et donne un score : points forts, trous à combler, formulations à revoir.

MVP

Adaptation du CV

L'IA reformule chaque expérience pour coller à l'offre. Comparaison avant/après côte à côte, tu gardes le contrôle.

MVP

Simulation d'entretien

Questions ciblées selon le poste (screen RH ou hiring manager). Feedback écrit après chaque réponse.

MVP

Coaching vocal

Tu réponds à voix haute, l'IA écoute et te dit si c'est clair, trop long, ou s'il manque un mot-clé.

MVP

Suivi des candidatures

Table + vue kanban : poste, entreprise, étape, date de relance, notes. Tout au même endroit.

  • Hors V1 : extension Chrome pour capturer les offres, lettre de motivation, recherche automatique d'offres, application mobile.

Le plan jour par jour

Chaque jour a son prompt prêt à coller dans Claude Code. Lance-le dans un dossier vide, puis relis et teste avant de passer au suivant.

J1

Analyse de compatibilité poste / CV

  • Créer le projet Next.js avec App Router et Tailwind.
  • Page d'analyse : zone de texte pour le CV, zone pour l'offre d'emploi.
  • Route API qui envoie les deux à Claude et renvoie un rapport structuré.
  • Affichage du résultat en trois colonnes : points forts, à reformuler, manquant.
Fin de journéeTu colles un CV et une offre, et tu vois immédiatement ce qui colle et ce qui manque.
Prompt Claude Code · J1
Crée une application Next.js (App Router, TypeScript, Tailwind), interface en français.
Page /analyse : deux zones de texte (CV à gauche, offre d'emploi à droite) et un bouton « Analyser ».
À l'envoi, appelle une route /api/analyze qui envoie les deux textes à l'API Claude (Sonnet) avec un prompt système qui demande de comparer le CV à l'offre et de renvoyer un JSON structuré : { strengths: [...], gaps: [...], rewrites: [...] }.
Affiche le résultat sous les zones de texte en trois colonnes colorées : vert (points forts), orange (à reformuler), rouge (manquant).
Ajoute un score de compatibilité en pourcentage en haut du résultat.
Gère les erreurs (API down, texte trop court). Ajoute .env.example avec ANTHROPIC_API_KEY.
J2

Adaptation automatique du CV

  • Depuis le résultat du J1, bouton « Adapter mon CV ».
  • L'IA reformule chaque bullet point pour coller à l'offre.
  • Affichage diff : version originale / version adaptée côte à côte.
  • Export PDF du CV adapté.
Fin de journéeTu passes de l'analyse à un CV retravaillé en un clic, exportable en PDF.
Prompt Claude Code · J2
Ajoute une fonctionnalité d'adaptation du CV au projet :
- Depuis la page /analyse, quand un résultat est affiché, ajoute un bouton « Adapter mon CV ».
- Au clic, appelle /api/tailor qui envoie le CV, l'offre et les gaps identifiés à Claude avec un prompt qui demande de réécrire chaque expérience pour mieux coller à l'offre, sans inventer.
- Affiche le résultat sur une page /tailor en deux colonnes : original à gauche, version adaptée à droite, avec les changements surlignés.
- L'utilisateur peut cliquer sur chaque bullet pour accepter ou rejeter la modification.
- Ajoute un bouton « Exporter en PDF » qui génère un PDF propre du CV adapté (utilise @react-pdf/renderer ou html2pdf.js).
Le CV exporté doit suivre le format français standard (photo optionnelle, expériences, formation, compétences).
J3

Simulation d'entretien + coaching vocal

  • Génération de questions ciblées selon le poste et le profil.
  • Mode texte : l'utilisateur tape sa réponse, feedback écrit.
  • Mode vocal : Web Speech API transcrit, l'IA évalue en temps réel.
  • Timer et indicateurs visuels (durée, mots-clés détectés).
Fin de journéeTu t'entraînes à un entretien réaliste avec feedback immédiat, par écrit ou à l'oral.
Prompt Claude Code · J3
Ajoute la simulation d'entretien au projet :
- Page /interview : l'utilisateur choisit le type (screen RH ou hiring manager) et le poste.
- /api/questions génère 8 questions ciblées via Claude, basées sur l'offre et le CV déjà analysés.
- Mode texte : l'utilisateur tape sa réponse dans un champ, puis /api/feedback évalue (clarté, pertinence, mots-clés manquants, longueur).
- Mode vocal : utilise la Web Speech API (navigator.mediaDevices + SpeechRecognition) pour transcrire la réponse en direct. Affiche un timer et un indicateur de volume. À la fin, envoie la transcription à /api/feedback.
- Le feedback s'affiche sous chaque question : note sur 10, points forts, axes d'amélioration.
- Résumé global à la fin de la session avec les 3 points à travailler.
Tout en français. Gère le cas où le navigateur ne supporte pas la Web Speech API (fallback texte).
J4

Suivi des candidatures + comptes

  • Connexion par lien magique avec Supabase (région UE).
  • Table candidatures avec CRUD complet.
  • Vue kanban en drag & drop.
  • Quota gratuit : 5 analyses et 3 simulations par mois.
Fin de journéeUn utilisateur crée un compte, suit ses candidatures en kanban et est limité par le quota gratuit.
Prompt Claude Code · J4
Ajoute Supabase au projet :
- Authentification par lien magique (email).
- Table applications (id, user_id, company, role, url, stage enum(prospect/applied/interview/offer/rejected), notes, next_action_date, created_at) avec Row Level Security.
- Page /tracker avec deux vues : table triable et kanban (colonnes = stages, drag & drop avec @dnd-kit/core).
- CRUD complet : ajouter, modifier, archiver une candidature.
- Table usage (user_id, month, analyses_count, interviews_count) pour le quota.
- Quota gratuit vérifié côté serveur : 5 analyses et 3 simulations par mois.
- Sauvegarde automatique des analyses et simulations précédentes, liées au profil.
Donne-moi le SQL de migration à exécuter dans Supabase.

Les risques à connaître

Le coût des appels APIChaque analyse envoie un CV + une offre à Claude. Avec Sonnet, ça revient à ~0,003 $ par appel. Le quota gratuit et l'abonnement Pro protègent ta marge, mais surveille ta facture dès les premiers utilisateurs.
La concurrence est fragmentée mais réelleJeTrichePas, AttractiveCV, JobCopilot et les outils US (Teal, Jobscan) existent. Ton avantage : le tout-en-un français avec coaching vocal. Ne te disperse pas.
La qualité de la reconnaissance vocaleLa Web Speech API fonctionne bien en français dans Chrome, mais pas dans tous les navigateurs. Prévois un fallback texte et sois transparent sur cette limite.
